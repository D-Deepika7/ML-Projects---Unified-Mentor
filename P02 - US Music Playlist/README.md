# US Top 50 Playlist Performance & Song Popularity Trend Analysis

## 📌 Project Overview

This project analyzes historical US Top 50 music playlist data to uncover trends in song popularity, playlist rankings, artist performance, and chart longevity.

The objective is to understand how songs perform over time, identify ranking patterns, evaluate artist dominance, and explore relationships between song attributes and popularity.

The project focuses on historical data analysis and business insights rather than prediction or recommendation.

## 🎯 Key Objectives

- Analyze daily playlist rankings and movement patterns.
- Identify songs with the longest chart presence.
- Measure ranking stability and volatility.
- Evaluate artist dominance and repeat appearances.
- Explore the relationship between popularity scores and playlist rankings.
- Compare performance based on explicit content, album type, song duration, and album size.
- Develop actionable insights to support music industry decision-making.

## 🛠️ Technology Stack

- **Python** – Data analysis and processing
- **Pandas & NumPy** – Data manipulation and numerical analysis
- **Matplotlib & Seaborn** – Data visualization
- **Plotly** – Interactive visualizations
- **Streamlit** – Interactive analytics dashboard
- **Jupyter Notebook** – Exploratory Data Analysis (EDA)

## 📊 Key Performance Indicators

- Days on Chart
- Average Rank
- Best Rank Achieved
- Rank Volatility Index
- Popularity Score Trend
- Artist Dominance Index
- Explicit Content Share

## 📈 Dashboard Features

- Playlist timeline explorer
- Song ranking trend analysis
- Artist dominance leaderboard
- Popularity vs. rank analysis
- Explicit vs. non-explicit performance comparison
- Interactive date, artist, song, rank, and album-type filters

## 📦 Project Deliverables

1. Exploratory Data Analysis (EDA) and research paper.
2. Interactive Streamlit analytics dashboard.
3. Executive summary with key findings and recommendations.
