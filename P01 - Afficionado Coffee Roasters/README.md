# Title: Data-Driven Forecasting & Peak Demand Prediction for Afficionado Coffee Roasters
Summary:

This project aims to develop a data-driven forecasting system to predict coffee sales across multiple stores at both hourly and daily levels. By leveraging historical transaction data, the system will identify future demand patterns, peak sales periods, and revenue trends.

The solution incorporates time-series modeling and machine learning techniques to generate accurate short-term (1–7 days) and medium-term (14–30 days) forecasts. It also provides uncertainty estimates to support better operational planning.

The final outcome includes:

•	📊 Predictive models for demand forecasting 
•	⏰ Peak-hour identification system 
•	🏪 Store-specific insights for inventory & staffing 
•	🌐 Interactive Streamlit dashboard 

Business Impact:

•	Reduce inventory waste 
•	Improve staff scheduling 
•	Enable proactive decision-making 
•	Increase customer satisfaction
